# Blackstock product standard

Blackstock is one product, not a collection of disconnected creator tools.

## Core loop
Channel context → live trends → explainable analysis → choose source/action → edit → package → publish → analytics → learn.

## Competitive bar
- Research must be at least as useful as dedicated YouTube research tools: channel-relative context, outliers, competitors, topic velocity and clear reasons.
- Repurposing must feel as immediate as specialist clipping tools: source → recommended moments/format → edit → publish, without fake virality scores.
- Editing must converge on transcript + timeline + media, not a wizard maze.
- Publishing and analytics must use official platform flows and real data; unavailable data is shown as unavailable rather than fabricated.

## UX rules
1. Public product name is only **Blackstock**.
2. Never show arbitrary “Chance”, “Virality”, or opaque 0–100 scores to users.
3. Every recommendation must answer “why?” with concrete signals.
4. Initial content appears progressively; long lists use lazy rendering and pagination.
5. Search/filter work is cancellable and debounced.
6. One obvious primary action per card/row.
7. Third-party YouTube references stay references; native YouTube Clip/Remix is the default external action. Local editing is for files the user owns or may use.
8. No fake analytics, fake channel data, fake uploads, or fake completion states.
