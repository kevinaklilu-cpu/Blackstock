# Blackstock 3.0.2 · Build 302

Discovery removes the outer scrolling container: results and detail panes use the remaining window height. Search no longer silently requires embeddable/syndicated videos and defaults to relevance. Videos that forbid embedding show an explanation and retain the YouTube link. Time, format and category filters remain explicit; API results are not guaranteed to match the personalized YouTube website.

Automatic clipping also samples image changes across the video, groups activity peaks with lead-in and tail, and adds non-overlapping visual candidates. These can be used without spoken words. The interface distinguishes measured visual activity from semantic sporting-event recognition. Silent visual clips preserve the full image, avoiding ungrounded face crops. This is a bounded image-difference heuristic, not a claim of goal recognition, perfect framing or viral quality.

The stop control stays usable during speech analysis. Project identity guards protect asynchronous visual analysis and focus results. Completion text distinguishes a prepared cut from a rendered file. Download format reachability is checked before selection.

Validation: local build and discovery audit; planner tests for still images, distinct variable-length activity intervals and bounds; actual silent tennis video analysis produced eight candidates; the reported tennis download completed both tracks with format checking. Full app UI and end-to-end publishing still require separate verification. No live upload was performed.
